CodeSync Platform - Frontend Implementation Context
Project Overview

CodeSync is a full-stack collaborative coding platform inspired by GitHub + VS Code + Replit.

The backend is built using:

Java 21
Spring Boot
Spring Security + JWT
Spring Data JPA
PostgreSQL
WebSocket (STOMP + SockJS)

The frontend should be built using:

Angular 20
Angular Material
RxJS
STOMP.js
Monaco Editor
Responsive design

The frontend should consume the existing REST APIs and WebSocket endpoints. Do NOT redesign backend APIs unless absolutely necessary.

Frontend Development Order

To minimize rework, build the frontend in this sequence:

Project setup – Angular Material, routing, theme, authentication infrastructure.
Authentication – Login, Register, JWT interceptor, route guards.
Dashboard – My Projects, Public Projects, Search, Create Project.
Project Management – Project details, edit/delete, fork, star/unstar.
File Explorer – Tree view, CRUD for files and folders.
Monaco Editor – File loading, editing, save/update content.
Code Execution – Language selector, Run button, output terminal.
Version Control – Commit dialog and commit history panel.
Realtime Collaboration – STOMP connection, collaborative editing, active users, cursor updates.
UI Polish – Responsive layout, dark/light theme, animations, loading states, error handling.
